
Crime Data Analysis Dashboard in Excel 🕵️‍♀️🔍
🔗 #ExcelDashboard #DataAnalysis #CrimeStats #PivotCharts #Visualization #MSExcel

I recently designed an interactive dashboard in Microsoft Excel to analyze and visualize crime data effectively. This project focused on making complex data more accessible and insightful using pivot tables, pivot charts, and slicers.

✅ Project Highlights:
Cleaned and organized raw crime data for clarity and consistency

Created pivot charts to explore trends by crime type, location, victim demographics, and time

Used conditional formatting and slicers to make the dashboard interactive

Visualized key insights such as crime hotspots, weapon usage, and age-wise victim distribution

🎯 Tools Used: Microsoft Excel | Pivot Tables | Pivot Charts | Data Cleaning | Dashboard Design

This project enhanced my ability to turn raw data into a powerful visual story that helps understand crime patterns and supports data-driven decision-making.
